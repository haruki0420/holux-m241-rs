# Bundled fonts

Inter and Noto Sans JP subsets, generated by `pnpm fonts` from the
characters used in `src/`. Both families are licensed under the SIL Open
Font License 1.1:

- https://github.com/rsms/inter/blob/master/LICENSE.txt
- https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE

Do not hand-edit these files. Add the UI text first, then run
`pnpm --dir crates/m241-app/ui fonts` and commit the regenerated files.

Generated files:

- inter-400.woff2 13404 bytes Inter 400
- inter-600.woff2 13768 bytes Inter 600
- noto-sans-jp-400.woff2 46580 bytes Noto Sans JP 400
- noto-sans-jp-600.woff2 46864 bytes Noto Sans JP 600
