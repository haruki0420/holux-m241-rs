# Bundled fonts

Inter, Noto Sans JP and JetBrains Mono subsets, generated by `pnpm fonts`
from the characters used in `src/`. All three families are licensed under
the SIL Open Font License 1.1:

- https://github.com/rsms/inter/blob/master/LICENSE.txt
- https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE
- https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt

Do not hand-edit these files. Add the UI text first, then run
`pnpm --dir crates/m241-app/ui fonts` and commit the regenerated files.

Generated files:

- inter-400.woff2 13404 bytes Inter 400
- inter-500.woff2 13696 bytes Inter 500
- noto-sans-jp-400.woff2 38904 bytes Noto Sans JP 400
- noto-sans-jp-500.woff2 38792 bytes Noto Sans JP 500
- jetbrains-mono-400.woff2 17296 bytes JetBrains Mono 400
